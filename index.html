Deep Learning Architecture

Hybrid BERT – BiLSTM Classifier

The proposed architecture combines DistilBERT contextual token embeddings with a Bidirectional LSTM sequential layer and a self-attention mechanism, capturing both word-level meaning and narrative structure simultaneously.

Input
Raw article text
→
DistilBERT
768-dim contextual embeddings × 128 tokens
→
BiLSTM
128 units × 2 directions, 2 layers
→
Attention
Token importance weighting
→
Dense
256→64 units, dropout 0.3
→
