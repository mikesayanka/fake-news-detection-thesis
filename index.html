Deep Learning Architecture

Hybrid BERT – BiLSTM Classifier

Combines DistilBERT contextual embeddings with a Bidirectional LSTM and self-attention, capturing both word-level meaning and the sequential narrative structure of a news article.

Live Fake News Detection

How this demo works: This is a browser-based simulation of the BERT+BiLSTM classifier trained in Phase 3. The actual model runs on a Python GPU server — it cannot run inside a browser. This demo replicates the model's behaviour using the same accuracy distribution (99.04%) and confidence score pattern observed in Phase 5 evaluation. WELFake mode streams real sample headlines from the dataset. Live News mode fetches real headlines from HackerNews and GNews — both support direct browser access with no API key needed.
